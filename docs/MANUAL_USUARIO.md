# Manual de usuario — AutoGestion

Atajos globales: `Ctrl+K` busca páginas · botón **¿Cómo usar?** lanza el recorrido · cada pantalla tiene su banner de 3 pasos (se puede ocultar).

## Recepcionista

1. **Recibir un auto:** Recepción → busca al cliente (documento, nombre o teléfono). Si existe, elige su tarjeta y su vehículo; si no, créalo con documento validado. Completa problema, combustible, km, daños y accesorios → Confirmar → anota el N.° y ve a Cotización para el diagnóstico.
2. **Cotizar:** elige recepción pendiente + mecánico (el sugerido es el menos ocupado) → registra el diagnóstico → agrega servicios y productos (total automático) → genera → **Aprueba** cuando el cliente acepte.
3. **Crear la OT:** Órdenes → elige cotización aprobada + mecánico → Crear.
4. **Cobrar:** Pago y Entrega → Cobrar → Boleta (DNI) o Factura (RUC + razón social + dirección) → método de pago → Confirmar → imprime o descarga el PDF → Registra la entrega.
5. **Clientes:** busca, abre fichas (vehículos, visitas, comprobantes) y lanza recepciones con el cliente precargado.

## Mecánico

1. Entra a **tu Panel**: saludo con tus pendientes priorizados.
2. **Iniciar → Pasar a prueba → Finalizar** cada OT con el botón grande. Al finalizar se habilita el cobro.
3. **+ Repuesto** en OT en proceso/prueba: elige producto (sin stock se bloquea) y cantidad; descuenta al instante.
4. Consulta el **Inventario** en lectura y tus **Órdenes** en el kanban.

## Almacenero

1. **Stock:** busca productos, mira precio, costo y margen; el semáforo avisa el stock bajo.
2. **Comprar:** pestaña Registrar compra → proveedor (o créalo con RUC validado) + documento + líneas con costo → Confirmar. Actualiza stock y último costo.
3. **Mermas y ajustes:** tipo + producto + cantidad + motivo obligatorio (queda tu usuario registrado).
4. **Movimientos:** filtra por tipo/fecha; el motivo sale en el tooltip. **Reportes → Inventario** para kardex y valorización.

## Administrador

Todo lo anterior, más: **Equipo** (crear/editar/desactivar personal, restablecer claves; nunca te desactives a ti mismo ni dejes al sistema sin ADMIN), **Gastos** (registra alquiler, servicios, sueldos en Reportes → Gastos), **Resultado** (utilidad estimada con fórmula visible), **anular comprobantes** con motivo (el número no se reutiliza) y **Reportes** completos con CSV.

## Glosario rápido

OT (orden de trabajo) · RUC (11 dígitos, empresas) · DNI (8 dígitos) · Boleta (consumidor final) · Factura (empresa, da crédito fiscal) · Serie + correlativo (folio único) · IGV 18 % · Kardex (cuenta corriente del producto) · Merma (pérdida auditada) · Utilidad estimada (ingresos sin IGV − consumos − gastos, académica).
